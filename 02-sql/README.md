# SQL

## О проекте

Практические задания по работе с базами данных с использованием SQL и PostgreSQL.

## Что изучал

- SELECT;
- WHERE;
- ORDER BY;
- GROUP BY;
- агрегатные функции;
- JOIN;
- работу с несколькими таблицами;
- фильтрацию и сортировку данных;
- написание SQL-запросов.

## Инструменты

- PostgreSQL
- pgAdmin

## Практика

В рамках обучения выполнял SQL-запросы для получения, фильтрации, группировки и объединения данных из различных таблиц.

Также выполнял практические задания на поиск и анализ данных в базе.

## Результат

Получил базовые практические навыки работы с SQL и PostgreSQL, необходимые для проверки данных при тестировании программного обеспечения.
