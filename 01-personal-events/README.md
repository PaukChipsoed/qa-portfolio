# Проект: тестирование функциональности «Личные события»

## О проекте

Тестирование функциональности «Личные события» в личном кабинете преподавателя образовательной платформы.

Функциональность позволяет преподавателю работать с личными событиями в календаре: создавать, просматривать, редактировать и удалять события.

## Что тестировал

- создание личного события;
- просмотр события в календаре;
- редактирование события;
- удаление события;
- проверку обязательных полей;
- проверку даты и времени;
- проверку длительности события;
- корректность отображения событий в календаре.

## Виды тестирования

- функциональное тестирование;
- Smoke-тестирование;
- регрессионное тестирование;
- Retest;
- позитивное тестирование;
- негативное тестирование;
- UI-тестирование;
- проверка валидации данных.

## Тестовая документация

В рамках проекта были подготовлены:

- тест-кейсы;
- чек-листы;
- баг-репорты;
- Test Plan;
- Test Report.

## API-тестирование

Для проверки API использовал Postman.

Проверял:

- HTTP-методы;
- статус-коды ответов;
- структуру JSON;
- корректность передаваемых параметров;
- успешные и ошибочные сценарии;
- создание, изменение и удаление личных событий.

В Postman использовал переменные окружения и тестовые скрипты для проверки ответов API.

## Найденные дефекты

В процессе тестирования были обнаружены и оформлены дефекты.

### BUG-01 — отсутствие подтверждения при удалении события

При удалении личного события отсутствует дополнительное подтверждение действия.

**Severity:** S2 — Major  
**Priority:** High

### BUG-02 — ошибка при создании события минимальной длительности

Невозможно создать событие с минимальной длительностью 5 минут при установленном шаге времени 10 минут.

**Severity:** S3 — Medium  
**Priority:** Medium

## Результат

По итогам тестирования основная функциональность создания, просмотра и редактирования личных событий работает корректно.

Были выявлены дефекты, требующие исправления перед массовым релизом. После исправлений рекомендуется провести повторное тестирование и Smoke-тестирование функциональности.
