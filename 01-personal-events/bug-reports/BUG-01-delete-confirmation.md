# BUG-01 — Отсутствует подтверждение при удалении личного события

## Описание

При удалении личного события отсутствует окно подтверждения действия.

Пользователь может удалить событие сразу после нажатия кнопки удаления, без дополнительного подтверждения.

## Предусловия

- Пользователь авторизован в личном кабинете преподавателя.
- В календаре существует созданное личное событие.

## Шаги воспроизведения

1. Открыть календарь преподавателя.
2. Выбрать существующее личное событие.
3. Нажать кнопку удаления события.

## Фактический результат

Личное событие удаляется без дополнительного подтверждения действия.

## Ожидаемый результат

Перед удалением отображается окно подтверждения, например:

> «Вы действительно хотите удалить это событие?»

Пользователь должен иметь возможность подтвердить или отменить удаление.

## Severity

**S2 — Major**

## Priority

**High**

## Статус

Open

## Рекомендация

Добавить подтверждение перед окончательным удалением личного события.
