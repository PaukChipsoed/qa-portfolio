# Test Report — Личные события

## Цель тестирования

Проверить корректность работы функциональности «Личные события» в личном кабинете преподавателя.

## Объект тестирования

Функциональность работы с личными событиями:

- создание;
- просмотр;
- редактирование;
- удаление.

## Проведённые проверки

В рамках тестирования выполнялись:

- функциональные проверки;
- Smoke-тестирование;
- регрессионное тестирование;
- позитивное и негативное тестирование;
- проверка валидации данных;
- UI-проверки;
- API-тестирование.

## Результаты

Основные сценарии создания, просмотра и редактирования личных событий работают корректно.

В процессе тестирования были обнаружены дефекты:

- отсутствие подтверждения при удалении события;
- невозможность создания события с минимальной длительностью 5 минут.

## Дефекты

| ID | Описание | Severity | Priority |
|---|---|---|---|
| BUG-01 | Отсутствует подтверждение при удалении | S2 Major | High |
| BUG-02 | Невозможно создать событие длительностью 5 минут | S3 Medium | Medium |

## Итог

Функциональность в целом работоспособна, однако перед массовым релизом рекомендуется исправить выявленные дефекты.

После исправления рекомендуется провести повторное тестирование и Smoke-тестирование функциональности.
