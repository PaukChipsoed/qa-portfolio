# Functional Checklist — Личные события

## Создание события

- [ ] Открывается форма создания личного события
- [ ] Можно заполнить обязательные поля
- [ ] Можно указать дату события
- [ ] Можно указать время начала
- [ ] Можно указать длительность
- [ ] Событие успешно сохраняется
- [ ] Созданное событие отображается в календаре
- [ ] Нельзя создать событие с некорректными данными
- [ ] Отображаются сообщения об ошибках при нарушении правил валидации

## Просмотр события

- [ ] Созданное событие отображается в календаре
- [ ] Отображаются корректные данные события
- [ ] Событие можно открыть для просмотра

## Редактирование события

- [ ] Событие можно открыть для редактирования
- [ ] Можно изменить данные события
- [ ] Изменения успешно сохраняются
- [ ] После сохранения отображаются обновлённые данные

## Удаление события

- [ ] Событие можно удалить
- [ ] После удаления событие исчезает из календаря
- [ ] Перед удалением отображается подтверждение действия

## Проверка времени и даты

- [ ] Можно создать событие на допустимую дату
- [ ] Можно указать корректное время начала
- [ ] Проверяется длительность события
- [ ] Проверяются граничные значения длительности
- [ ] Нельзя сохранить событие с недопустимыми значениями
