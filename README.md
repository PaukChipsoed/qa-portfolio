### 01. Тестирование функциональности «Личные события»

Комплексное тестирование функциональности создания, просмотра, редактирования и удаления личных событий в календаре преподавателя.

В рамках проекта выполнялись:

- анализ требований;
- подготовка тестовой документации;
- функциональное тестирование;
- smoke-тестирование;
- регрессионное тестирование;
- позитивное и негативное тестирование;
- тестирование API;
- оформление и проверка баг-репортов;
- подготовка итогового тестового отчёта.
