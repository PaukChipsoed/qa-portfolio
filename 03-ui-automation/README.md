# UI Automation

## О проекте

Учебные UI-тесты веб-приложений на Python с использованием Selenium WebDriver и Pytest.

## Что изучал

- написание автотестов на Python;
- Selenium WebDriver;
- Pytest;
- поиск элементов на странице;
- CSS-селекторы и XPath;
- работу с браузером;
- ожидания элементов;
- проверку URL и содержимого страницы;
- работу с динамическими элементами;
- взаимодействие с формами;
- работу с cookies.

## Примеры автоматизированных проверок

- проверка навигации между страницами;
- заполнение формы и отправка данных;
- поиск и проверка нескольких элементов;
- ожидание появления динамического контента;
- проверка cookies и пользовательских данных.

## Инструменты

- Python
- Selenium WebDriver
- Pytest
- Chrome / Edge
- Git
- GitHub

## Результат

Получил базовый практический опыт автоматизации UI-тестов и написания автотестов на Python с использованием Selenium WebDriver и Pytest.
